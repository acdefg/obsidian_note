# 背包问题：0-1 与完全

> 原型图：![[0-1背包 完全背包-1793026959479.webp]]
>
> 全文只讲一条主线：**两种背包的二维转移只差一个下标（`i-1` 还是 `i`）；压成一维后，这个差别就变成"内层逆序"还是"内层正序"。**

## 先看结论：一张总表 #dp

| 目标               | 物品用量 | 二维转移                              | 一维内层方向          | 初始化                 | 答案                  |
| ---------------- | ---- | --------------------------------- | --------------- | ------------------- | ------------------- |
| **至多 W**（原型图这题）  | 0-1  | `max(dp[i-1][j], dp[i-1][j-w]+v)` | **逆序** `j: W→w` | 全 0                 | `dp[W]`             |
| **至多 W**         | 完全   | `max(dp[i-1][j], dp[i][j-w]+v)`   | **正序** `j: w→W` | 全 0                 | `dp[W]`             |
| **恰好 W**         | 0-1  | `max(dp[i-1][j], dp[i-1][j-w]+v)` | **逆序**          | `dp[0]=0`，其余 `-INF` | `dp[W]`；`-INF` = 无解 |
| **恰好 W**         | 完全   | `max(dp[i-1][j], dp[i][j-w]+v)`   | **正序**          | `dp[0]=0`，其余 `-INF` | `dp[W]`；`-INF` = 无解 |
| **方案数（恰好 W，组合）** | 0-1  | `dp[i-1][j] + dp[i-1][j-w]`       | **逆序**          | `dp[0]=1`，其余 0      | `dp[W]`             |
| **方案数（恰好 W，组合）** | 完全   | `dp[i-1][j] + dp[i][j-w]`         | **正序**          | `dp[0]=1`，其余 0      | `dp[W]`             |
| **方案数（恰好 W，排列）** | 完全   | —（换循环顺序）                          | 外层容量、内层物品       | `dp[0]=1`           | `dp[W]`             |
| **最少物品数（恰好 W）**  | 0-1  | `min(dp[i-1][j], dp[i-1][j-w]+1)` | **逆序**          | `dp[0]=0`，其余 `+INF` | `dp[W]`；`INF` = 无解  |
| **最少物品数（恰好 W）**  | 完全   | `min(dp[i-1][j], dp[i][j-w]+1)`   | **正序**          | `dp[0]=0`，其余 `+INF` | `dp[W]`；`INF` = 无解  |

**读表要先分清两个维度：**

1. **目标**——"至多 W"（不超过容量）和"恰好 W"是两个不同的问题。**转移式的形状一样，但状态定义不同**：至多的 `dp[j]` 是"不超过 j"，恰好的 `dp[j]` 是"恰好 j"。所以初始化不同，答案里 `-INF` 的含义也不同（不可达）。
2. **物品用量**——0-1 还是完全，**只差一维的内层方向**。

> ⚠️ **本表并存两套状态定义，不要混用**：
> - **至多行**：`dp[j]` = 容量**不超过** j → 初始化全 0，答案 `dp[W]`。
> - **恰好行**：`dp[j]` = 容量**恰好** j → 初始化 `dp[0]=0` 其余 `-INF`，答案 `dp[W]`（`-INF` = 无解）。
>
> 也可以统一用"恰好 j"：此时"至多"的答案要写 `max(dp[0..W])`，初始化全用 `-INF`。两种写法等价，但**同一份代码里只能选一种**。

## 一、0-1 背包怎么做 #dp

**问题**：有 n 件物品，第 i 件体积 `w[i]`、价值 `v[i]`。每件**最多选一次**，总体积不超过 W，求最大价值和。

### 1. 先写递归

按"回溯三问"拆：当前这件选还是不选？

```
dfs(i, c) = 第 i 件（下标从 1 开始）、剩余容量 c 时的最大价值

不选第 i 件：  dfs(i-1, c)
选第 i 件：    dfs(i-1, c - w[i]) + v[i]
                             ↑ 用了 i-1：第 i 件已经用掉，不能再选

dfs(i, c) = max( dfs(i-1, c), dfs(i-1, c - w[i]) + v[i] )
dfs(0, c) = 0
```

**注意第二项的下标是 `i-1`**——这是 0-1 的定义带来的：用完这件，就只剩前 i-1 件可用。

### 2. 改成二维递推

`dp[i][j]` = 前 i 件物品、容量 j 能拿到的最大价值。

```cpp
for (int i = 1; i <= n; ++i)
    for (int j = 0; j <= W; ++j) {
        dp[i][j] = dp[i-1][j];                       // 不选
        if (j >= w[i-1])                             // 容量够才考虑选
            dp[i][j] = max(dp[i][j], dp[i-1][j - w[i-1]] + v[i-1]);
    }
```

- 时间 `O(nW)`，空间 `O(nW)`。
- 答案：`dp[n][W]`。

### 3. 压成一维：为什么内层必须逆序

第 i 行只依赖第 i-1 行，所以可以只保留一行。压完之后：

```cpp
dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
```

问题是：这里的 `dp[j-w[i]]` 必须读到**上一行（i-1）** 的值。而一维数组里没有"行"的概念，读到的是上一行还是本行，完全取决于**内层 j 的遍历方向**。

- 如果 `j` 从 **小到大（正序）**：走到 j 时，`j-w` 比 j 小，**已经被本轮改过了** → 读到的是第 i 行 → 相当于这件物品可以被重复选。
- 如果 `j` 从 **大到小（逆序）**：`j-w` 还没被本轮碰过 → 读到的仍是第 i-1 行 → 每件只用一次。

所以：

```cpp
for (int i = 0; i < n; ++i)
    for (int j = W; j >= w[i]; --j)          // 逆序
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
```

### 4. 手推一遍（W=5，物品 w=2, v=3）

初始 `dp = [0,0,0,0,0,0]`，逆序处理这一件：

| j | 计算 | dp[j] |
|---|---|---|
| 5 | `max(0, dp[3]+3=3)` | 3 |
| 4 | `max(0, dp[2]+3=3)` | 3 |
| 3 | `max(0, dp[1]+3=3)` | 3 |
| 2 | `max(0, dp[0]+3=3)` | 3 |

结果 `dp[5] = 3`：容量 5 也**只装得下一件**（两件需要容量 4，但每件只能用一次）。

### 5. 初始化：至多 vs 恰好

| 目标 | 初始化 | 说明 |
|---|---|---|
| 至多 W | `dp[0..W] = 0` | "容量 j 不装任何东西"是合法解 |
| 恰好 W | `dp[0] = 0`，其余 `-INF` | 除 0 容量外都还不可达 |

求"恰好"时，转移前要判可达：

```cpp
for (int j = W; j >= w[i]; --j)
    if (dp[j-w[i]] != NEG)
        dp[j] = max(dp[j], dp[j-w[i]] + v[i]);
```

用 `W=5`、只有一件 `(3,5)` 验算：

- 至多：`dp[5] = 5`（装 3，剩 2 空着）
- 恰好：`dp[5] = -INF`（凑不出 5，无解）

## 二、完全背包怎么做 #dp

**问题**：同上，但每件物品可以选**任意多次**。

### 1. 递归只改一个下标

```
不选第 i 件：  dfs(i-1, c)
选第 i 件：    dfs(  i  , c - w[i]) + v[i]
                   ↑ 还是 i：选完之后仍然站在第 i 件面前，可以再选

dfs(i, c) = max( dfs(i-1, c), dfs(i, c - w[i]) + v[i] )
```

**唯一的差别就是这一处 `i-1 → i`。** 它表达的是"选完还能再选"。

### 2. 二维递推

```cpp
for (int i = 1; i <= n; ++i)
    for (int j = 0; j <= W; ++j) {
        dp[i][j] = dp[i-1][j];
        if (j >= w[i-1])
            dp[i][j] = max(dp[i][j], dp[i][j - w[i-1]] + v[i-1]);
        //                                 ↑ i，不是 i-1
    }
```

### 3. 压成一维：内层改成正序

完全背包压一维时，`dp[j-w]` 需要读到**本行（第 i 行）** 的值——因为本行已经表示"可以重复选第 i 件"。

- `j` 从 **小到大（正序）**：`j-w` 刚被本轮更新过 → 读到的正是本行 → 允许重复选。
- 所以内层顺序**恰好和 0-1 相反**。

```cpp
for (int i = 0; i < n; ++i)
    for (int j = w[i]; j <= W; ++j)          // 正序
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
```

### 4. 手推一遍（同样的 W=5，物品 w=2, v=3）

初始 `dp = [0,0,0,0,0,0]`，正序处理：

| j | 计算 | dp[j] |
|---|---|---|
| 2 | `max(0, dp[0]+3=3)` | 3 |
| 3 | `max(0, dp[1]+3=3)` | 3 |
| 4 | `max(0, dp[2]+3=**6**)` | 6 |
| 5 | `max(0, dp[3]+3=**6**)` | 6 |

结果 `dp[5] = 6`：`j=4` 时读到的 `dp[2]` 已经是**本轮**写入的 3，相当于又装了一件。

**同一组数据、同一件物品，逆序得 3、正序得 6。这就是两种背包的全部差别。**

### 5. 初始化

和 0-1 完全一样：至多就全 0，恰好就 `dp[0]=0` 其余 `-INF`，且转移前判可达。

## 三、两者的唯一差别 #dp

| | 0-1 背包 | 完全背包 |
|---|---|---|
| 每件可用次数 | 1 | 无限 |
| 递归第二项 | `dfs(i-1, c-w)` | `dfs(i, c-w)` |
| 二维转移 | `dp[i-1][j-w] + v` | `dp[i][j-w] + v` |
| 一维内层 | **逆序** `j: W→w` | **正序** `j: w→W` |
| 一维里 `dp[j-w]` 实际读到 | 上一行（旧值） | 本行（刚更新的值） |
| 记忆口诀 | 不敢用刚更新的值 | 敢用刚更新的值 |

**记不住方向时，回到二维式子看第二项的下标：`i-1` → 逆序，`i` → 正序。** 不用背。

## 四、其他情况与易错清单 #dp

### 1. 求方案数

初始化改成 `dp[0] = 1`，其余为 0；转移从 `max` 换成 `+=`。

**为什么是 1 不是 0**：`dp[0]` 表示"凑出容量 0 的方案数"，而**空集本身就算一种方案**（组合计数的约定：空积为 1）。它是整个递推的种子——`dp[j] += dp[j-w]` 在 `j == w` 时读到的正是 `dp[0]`；种子若是 0，"用一枚硬币刚好凑出"这条路径就消失了。

验算 `{2}`、`W=4`：种子为 1 → `[1,0,1,0,1]`；种子为 0 → `[0,0,0,0,0]`，整条链全塌。

另外，**计数问题不需要 `INF`**：`0` 已经同时表示"还没有任何方案"和"不可达"，两者在这里是一回事。

**组合数**（顺序无关，如 518 零钱兑换 II）——外层物品、内层容量：

```cpp
for (int i = 0; i < n; ++i)
    for (int j = w[i]; j <= W; ++j)      // 0-1 用逆序，完全用正序
        dp[j] += dp[j - w[i]];
```

**排列数**（顺序有关，如 377 组合总和 IV）——外层容量、内层物品：

```cpp
for (int j = 1; j <= W; ++j)
    for (int i = 0; i < n; ++i)
        if (j >= w[i])
            dp[j] += dp[j - w[i]];
```

外层循环物品时，物品的加入顺序被固定，所以 `1+2` 和 `2+1` 算同一种；外层循环容量时，每一步都能任选物品，所以两种顺序会被分别计数。

例：硬币 `{1,2,5}` 凑 5，组合数 **4**（`5`、`2+2+1`、`2+1+1+1`、`1×5`），排列数 **9**。

### 2. 求最少物品数

把 `max` 换成 `min`、`+v` 换成 `+1`，初始化 `dp[0]=0`、其余 `+INF`，转移前判 `!= INF`。典型题：322 零钱兑换（完全背包）。

**为什么这样初始化**：`dp[0]=0` 表示"凑 0 元要 0 枚"；其余位置一开始"还不知道能不能凑出"，必须填一个**比任何真实答案都大**的哨兵，因为 `min` 会选小值——若填 0，所有位置会立刻被 0 压住，答案全变成 0。

验算 `{2}`、`W=3`：正确初始化得 `dp[3] = +INF`（凑不出）；若其余填 0，则 `dp[3] = 0`（错，会说 3 元不用硬币）。

转移时判 `dp[j-w] != INF` 是必须的：`INF + 1` 会溢出成负数，一旦溢出反而会被 `min` 选中。

**四类初始化其实是同一句话**：初始值 = "什么都不选"这个状态在该问题下的答案。

| 问题 | `dp[0]` | 其余 `j>0` | 理由 |
|---|---|---|---|
| 最大价值（恰好 W） | 0 | `-INF` | 空集价值 0；其他容量空集凑不出 |
| 最小价值 / 最少物品数（恰好 W） | 0 | `+INF` | 空集计数 0；其他容量不可达，且不能小到被 `min` 选中 |
| 方案数（恰好 W） | **1** | 0 | 空集**是**一种方案；其他容量目前 0 种 |
| 至多 W（任何目标） | 0 | 0 | 任何容量都允许空集 |

### 3. 其他变体

| 变体 | 循环结构 | 要点 |
|---|---|---|
| 多重背包（每件有数量上限 k） | 二进制拆分后套 0-1 | 把 k 件拆成 1,2,4,…,余数，可组合出 0..k 任意数量 |
| 分组背包（每组最多选一件） | 组 → 容量（逆序）→ 组内物品 | 组内互斥，所以容量循环夹在中间 |
| 二维费用（体积 + 重量两个约束） | 物品 → 容量1（逆序）→ 容量2（逆序） | 两个约束都要满足，0-1 时两层都逆序 |
| 存在性（能否凑出） | 同方案数，`bool` 或 `bitset` | 转移用 `|=` |

**416 的参考实现**（0-1 · 恰好 · 可达性）：

```cpp
bool canPartition(vector<int>& nums) {
    int sum = accumulate(nums.begin(), nums.end(), 0);
    if (sum % 2) return false;           // 奇数不可能平分
    int W = sum / 2;
    vector<char> f(W + 1, false);
    f[0] = true;
    int reach = 0;                       // 已处理元素目前能凑出的最大容量
    for (int x : nums) {
        reach = min(reach + x, W);       // 上界剪枝：不超过 W
        for (int j = reach; j >= x; --j) // 0-1，必须逆序
            f[j] |= f[j - x];
        if (f[W]) return true;
    }
    return false;
}
```

两个细节：`reach` 把内层上界从固定的 `W` 收窄到"当前可能达到的最大值"；`f` 用 `vector<char>` 而不是 `vector<int>`（浪费）或 `vector<bool>`（代理容器、有额外开销）。

**两个提醒：**

- 完全背包的"至多"在 LeetCode 上很少见，主流题都要求**恰好**（因为无限物品下"不超过"往往可以直接凑满）。
- **198 / 213 打家劫舍不是背包**：它是线性 DP（相邻不能同时选），别和 0-1 背包混为一类。两者的"选或不选"只是表面相似，约束不同。

### 5. 易错清单

1. **0-1 写成正序** → 悄悄变成完全背包，答案偏大（上例 3 会变成 6）。
2. **完全写成逆序** → 退化成 0-1，答案偏小。
3. **内层下界写成 `j > w[i]`** → 漏掉"单件刚好装满"的状态。`W=2`、物品 `w=2` 时循环一次都不执行。
4. **恰好装满忘改初始化** → 把"没装满"当成合法解，答案偏大。
5. **`INF + v` 溢出** → 用 `long long`，或先判 `dp[j-w] != INF`。
6. **状态定义混用** → `dp[j]` 一会儿表示"不超过 j"、一会儿表示"恰好 j"，答案取 `dp[W]` 还是 `max(dp[0..W])` 会打架。选定一种，全文统一。
