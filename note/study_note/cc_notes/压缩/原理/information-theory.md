# 信息论根基

> **这是压缩算法系列的最底层。** 它回答两个问题：① 为什么压缩存在极限；② 极限由什么量刻画。
> 后面所有算法（Huffman、算术编码、LZ、ANS、PPM、变换编码……）都是在逼近这些界，或用工程代价换取逼近。
>
> **约定**：`log` 以 2 为底，单位 bit。
> **标注**：【理论】= 定义/定理/可证明的界；【工程】= 0.对实际压缩器的约束或指导。

## 熵是什么？为什么它给出压缩的下界？ #compression #theory

> **速查**
> - 熵 `H(X) = -Σ p(x)·log₂p(x)`，即**平均意外程度**：`I(x) = -log₂p(x)` 是单个符号的信息量
> - 取值范围 `0 ≤ H(X) ≤ log₂|Σ|`：下界是"某符号必然出现"，上界是"均匀分布"
> - `|Σ|=256`（一个字节）且均匀分布时，`H = 8 bit` —— **这正是原始字节表示的信息量**
> - **熵是无损压缩的每符号下界**：任何前缀码的平均码长都不可能低于 `H(X)`
> - 它衡量的是**分布的形状**，不是某一次具体输出

### 正文

**定义**：

```
H(X) = -Σ_x p(x) · log₂ p(x)  =  E[ -log₂ p(X) ]
```

符号逐个解释：

| 符号 | 含义 |
|---|---|
| `X` | 离散随机变量，取值来自**符号表** `Σ`（例如英文字母表 `{a,…,z,空格}`）。它是"信源"的模型 |
| `x` | `Σ` 中的一个具体取值（一个符号） |
| `p(x)` | 符号 `x` 出现的概率，满足 `p(x) ≥ 0`、`Σ_x p(x) = 1` |
| `log₂` | 以 2 为底，使结果单位为 bit |

**直观含义**：单个符号的**信息量**（surprisal，意外度）定义为 `I(x) = -log₂ p(x)`：

- `p(x) = 1`（必然发生）→ `I = 0` bit：毫无意外的符号不携带信息
- `p(x) = 1/2` → `I = 1` bit：把一次五五开的选择记住需要 1 bit
- `p(x) → 0` → `I → ∞`：越罕见的符号，出现时信息量越大

**熵就是意外度的期望值**——"平均每个符号带来多少 bit 的不确定度"。

**为什么熵是下界**（证明在第 3 节，依赖 Kraft 不等式）：任何**前缀码**（任何码字都不是另一个码字前缀的编码）为符号 `x` 分配的码长 `l(x)`，其"每单位概率的编码开销"受 Kraft 约束，使平均码长不可能低于 `H(X)`。换句话说，**熵是"用整数比特标注每个符号"这件事的物理下界**。

## 条件熵与互信息：为什么"利用上下文"能降熵 #compression #theory

> **速查**
> - **链式法则**：`H(X,Y) = H(X) + H(Y|X)` —— 把两个变量一起记，bit 数 = 先记 X + 已知 X 后记 Y
> - **互信息** `I(X;Y) = H(X) - H(X|Y) ≥ 0`，即 **`H(X|Y) ≤ H(X)`：条件化永不增加熵**
> - 一切上下文建模压缩器（LZ、PPM/CM、LLM 预测）都在做同一件事：**把估值从 `p(x)` 换成 `p(x|上下文)`**
> - **压缩器的本质就是上下文的函数**
> - 符号独立时 `H(Xⁿ) = n·H(X)`，上下文无用；符号相关时 `H(Xⁿ) < n·H(X)`，省下 `Σ I(Xᵢ; X^{<i})` bit

### 正文

**条件熵**：`H(Y|X) = Σ_x p(x)·H(Y|X=x)`——"已知 X 后 Y 的剩余不确定度"，即"对每个 x 先算 `H(Y|X=x)`，再按 `p(x)` 加权平均"。

**链式法则**：`H(X,Y) = H(X) + H(Y|X)`，推广到 n 个变量：

```
H(X₁,…,Xₙ) = Σᵢ H(Xᵢ | X_{i-1},…,X₁)
```

**这个求和式是"上下文为什么有用"的数学核心。**

**互信息**：`I(X;Y) = H(X) - H(X|Y) ≥ 0`（`I = 0` 当且仅当两者独立）。

由 `I ≥ 0` 立即得到 `H(Xᵢ | X_{i-1},…,X₁) ≤ H(Xᵢ)`——**"已知前面符号后，下一个符号的剩余熵"不会超过它的边际熵**。

代入链式求和：一条 n 长消息的总熵等于各步条件熵之和；**只要数据里有可被前面符号预测的部分（`I > 0`），对应项就比"当作独立符号"小**。

**工程含义**：一切上下文建模压缩器都在做同一件事——把估值从边际分布 `p(x)` 换成条件分布 `p(x|上下文)`，从而逼近更小的条件熵。**压缩器的本质就是上下文的函数。**

- 所有区间都在 `[0,1)` 内。

总宽度 ≤ 1，直接得出。**McMillan 定理**进一步说明：对任何**唯一可解码**的码，Kraft 同样成立。所以**最优前缀码 = 最优唯一可解码码**。

**定理**：无记忆源存在无前缀二进制码使 `H(X) ≤ L < H(X) + 1`，其中 `L = Σ p(x)·l(x)` 是平均码长。

**上界那 1 bit 的来源**（回答"为什么整数比特带来损失"）：

取 `l(x) = ⌈-log₂p(x)⌉`（向上取整），则：

1. `2^(-l(x)) ≤ p(x)`，故 `Σ 2^(-l(x)) ≤ Σ p(x) = 1` —— **Kraft 满足**，前缀码存在；
2. `l(x) < -log₂p(x) + 1`，加权求和得 `L < H(X) + Σp(x) = H(X) + 1`。

**机制**：理想码长一般是**非整数**。整数码字必须向上取整，每个符号多花"不到 1 bit"，按概率加权后总额外开销也"不到 1 bit"。**所以它不是每符号 1 bit 的固定税，而是每传一个码字最多 1 bit 的边界税。**

**如何消掉**：

- **块编码**：把 n 个符号打包成"超符号"再编码 → `Lₙ/n < H(Xⁿ)/n + 1/n`。对无记忆源 `H(Xⁿ) = nH(X)`，得 `Lₙ/n → H(X)`，**每符号的 1 bit 税摊成 1/n 并趋于 0**。
- **算术编码**：把整条消息映射到 `[0,1)` 上一个子区间，用区间内一个点表示消息。消息概率 `P = Πp(xᵢ)`，区间长度恰为 `P = 2^(-L*)`，其中 `L* = -Σlog₂p(xᵢ)`。输出约 `⌈L*⌉+1` bit，即 **`n·H + O(1)`**——**`O(1)` 与 n 无关，而不是 n 的每符号税**。

**渐近均分性（AEP）**：对 i.i.d. 源，`-(1/n)log₂p(Xⁿ) → H(X)`（依概率）。于是"典型集"大小约 `2^(nH)`，用 `n(H+ε)` bit 定长编码即可，且不可能再用更少。

## 无记忆源 vs 有记忆源：熵率 #compression #theory

> **速查**
> - **无记忆源**（i.i.d.）：`H(Xⁿ) = n·H(X)`，第 3 节的界就是最终答案
> - **有记忆源**：真实极限是**熵率** `H(𝒳) = lim (1/n)H(X₁,…,Xₙ) = lim H(Xₙ|X_{n-1},…,X₁)`（平稳过程下两式相等）
> - **有记忆时 `H(𝒳) ≤ H(X₁)`**，通常严格小于：**逐符号边际熵是"高估"**
> - **一阶马尔可夫源**：`H(𝒳) = H(X₂|X₁) = Σᵢ πᵢ Σⱼ Pᵢⱼ log₂(1/Pᵢⱼ)`（`P` 转移概率，`π` 平稳分布）
> - ⚠️ **自然语言的熵率至今没有收敛的定论**——即使上下文窗开到很大，实测码长仍缓慢下降、看不到平台期

### 正文

**为什么真实数据的"逐符号熵"不是真实极限**：文本、图像、音频都有**长程相关**（远距离依赖），不是有限阶马尔可夫。用"单符号频率分布"算熵（零阶熵）只是**上界**；真实极限是**熵率** `H(𝒳)`，它需要任意长的上下文才能逼近。

> ⚠️ **重要补充**：对自然语言，即使把上下文窗口开到很大，实测码长仍在缓慢下降、**看不到平台期**。这意味着自然语言熵率的具体数值至今没有定论，甚至有人猜测它随 `N→∞` 趋于 0。**不要把它当成一个已确定的常数。**

## Kolmogorov 复杂度与 MDL #compression #theory

> **速查**
> - **Kolmogorov 复杂度** `K_U(x) = min{|p| : U(p) = x}`——生成 `x` 所需**最短程序的长度**，即"x 的最短描述"
> - **不变性定理**：换一台通用机，`K` 只差一个与 `x` 无关的常数 → 良定义
> - ⚠️ **不可计算**：不存在程序能对所有 `x` 算出 `K(x)`（否则可判定停机问题）
> - **绝大多数 n bit 串满足 `K(x) ≥ n - O(1)`** —— 随机串不可压缩
> - **与熵的关系**：对可计算分布 `P`，`E[K(x)] = H(P) + O(1)`
> - **推论**：**任何实际压缩器都是 `K(x)` 的一个上界**，而由不可计算性，**没有任何实际算法能保证达到它**

### 正文

**与香农熵的区别**：

- **对象不同**：香农熵是对**分布/信源**取平均（需先给定 `p`）；Kolmogorov 复杂度是**单个字符串**的属性（无需分布）
- **联系**：对可计算分布 `P`，`E_{x~P}[K(x)] = H(P) + O(1)`，且逐串地 `K(x) ≤ -log₂P(x) + O(1)`

**MDL（最小描述长度，Rissanen）**：描述 = **模型**部分 + **给定模型后的数据**部分，两部分长度之和即总描述长度。理论基座正是上面的关系：**寻找好的压缩器 = 从可计算分布族中选 `P`，使 `-log P(x)` 小**。

**为什么这条对本系列重要**：它给"压缩"一个绝对定义（最短描述），同时说明这个定义**在计算上不可达**。实际压缩器只能在可计算的分布族里逼近。

## 典型数据的实际熵（量级参考） #compression #data

> **速查**
> - ⚠️ **以下都是"取决于语料"的区间，不是普适常数**
> - **英文文本**：Shannon 1951 估计 **0.6–1.3 bit/字符**（常引 ≈1.0）；ASCII 原始是 **8 bit/字符** → **冗余约 87%**
> - ⚠️ **现代 LLM 给出的 0.66–0.69 bit/字符很可能乐观**（训练/测试集重叠、字母表口径不同，**不可与上表横比**）
> - ⚠️ 有研究指出熵率**不是固定常数**：儿童读物约 2 bpc，现代诗歌约 6 bpc，小说/论文接近 1 bpc
> - **中文**：零阶约 **9.6 bit/汉字**；含上下文约 **4–5 bit/汉字**（数值来自较早期文献，未复核）
> - **图像（无损）**：PNG 自然照片约 **11–12 bit/像素（约 2:1）**——自然照片是 PNG 最差的一类
> - **音频（无损）**：FLAC 通常压到原始 **50%–70%**；通用算法（ZIP）对 CD 音频只压 10%–40%

### 正文

**英文文本的各家估计**：

| 来源 | 数值 (bit/字符) | 备注 |
|---|---|---|

| Shannon 1951（长程外推） | 0.6–1.3，约 1.0 | 人工实验，**仅一位受试者**，统计学上被后人质疑 |

| Ren et al. 2019（众包猜字） | ≈ 1.22 | 大规模复现 |
| 现代 LLM 作预测器 | 0.66–0.69 | ⚠️ **很可能乐观**，口径不同 |

**关键对照**：ASCII 英文文本原始 = **8 bit/字符**。若真实熵率约 1 bit/字符，则**冗余度约 87%**（Shannon 原话常引"约 80% 冗余"，以随机文本 `log₂27≈4.75 bit/字符` 为基准）。

**中文**：

- **零阶**（仅字符频率）：约 **9.6 bit/汉字**（汉字容量极限定律：字符集超过约 12366 后趋于 9.65）
- **含上下文的极限熵（声称为上界）**：约 **4–5.17 bit/汉字**（吴军、王作英 1996 给上界 5.17）
- **工程参考**：UTF-8 下一个常用汉字 3 字节 = 24 bit；GB2312 下 2 字节 = 16 bit

**音频**：CD 原始 16 bit × 44100 Hz × 2 声道 = **1411 kbit/s**。FLAC 通常压到 50%–70%；静音接近 0%，噪声/重金属可能只压到 80–90%。

## 可逆变换不降熵，那变换有什么用？ #compression #theory

> **速查**
> - ⚠️ **若变换 `T` 可逆（双射），则 `H(T(X)) = H(X)`** —— 熵不会因可逆变换减少哪怕 1 bit
> - 这一点常被"变换能压缩"的说法误导，**必须澄清**
> - **变换真正做的**：把**多信息 / 总相关** `C = ΣᵢH(Xᵢ) - H(X₁,…,Xₙ) ≥ 0` 推向 0
> - **机制**：若编码器对每个分量**独立**做熵编码，总码率是 `ΣH(Xᵢ) ≥ H(Xⁿ)`，**浪费了 C bit**；去相关后 `ΣH(Xᵢ) → H(Xⁿ)`，独立分量编码器就能命中联合熵
> - **一句话**：变换不降熵，它把熵重新"摆布"，**使一个结构简单的（分量的、可并行的）编码器能够命中联合熵**
> - **有损管线例外**：量化是多对一，**真正降熵**——这才是有损能大幅低于无损极限的原因

### 正文

`C = Σᵢ H(Xᵢ) - H(X₁,…,Xₙ) ≥ 0`，`C = 0` 当且仅当各分量**相互独立**。`C > 0` 说明分量间有统计依赖，"分开各自编码"会浪费 `C` bit。

**常见去相关手段**【工程】：

- **线性/正交变换**：KLT（Karhunen-Loève，即 PCA 在信号上的形式，使分量方差互不相关且能量最集中）、DCT（JPEG/视频用）、色彩变换 RGB→YCbCr、小波变换（JPEG 2000）
- **预测去相关**：DPCM / 线性预测（音频）——对每个样本记"与预测值的残差"，残差的条件熵远小于原样本边际熵（等价于第 2 节的上下文降熵在数值信号上的应用）

这些变换在**无损管线**里必须严格可逆（整数小波、整数 DCT/lifting 方案）。

**有损管线的额外机制**：变换后接**量化**。量化是多对一映射，**不可避免地丢弃信息、真正降低熵**——这才是有损压缩能大幅低于无损极限的原因。

**所以两条界要分清**：

| 管线 | 支配它的界 |
|---|---|
| 可逆变换 + 无损熵编码 | 无损极限（`H(X)` / 熵率） |
| 变换 + 量化 + 熵编码 | 有损率失真曲线 `R(D)` |

## 一页速览（结论链）

1. **熵 `H(X)`** = 平均意外度 = 无损压缩的**每符号下界**。
2. **条件熵/互信息**说明上下文的价值：估值从 `p(x)` 换成 `p(x|上下文)`。
3. **香农定理**：`H ≤ L < H+1`；那个 `1` 来自整数码长的向上取整，是**每码字**的边界税；块编码/算术编码把每符号税压到 `O(1)/n → 0`。
4. **有记忆源**的真实极限是**熵率** `H(𝒳)`，逐符号边际熵只是上界；真实数据长程相关，熵率至今无确定数值。
5. **Kolmogorov 复杂度**给出"最短描述"的绝对定义，不可计算；期望上等于熵，故**实际压缩器都是它的上界、无法保证达到**；MDL 由其导出。
6. **量级**：英文 ≈1 bit/字符（vs 8 bit/字符 ASCII，冗余 ~87%）；中文零阶 ≈9.6 bit/汉字、含上下文 ≈4–5 bit/汉字（不确定）；PNG 自然照片 ≈11–12 bpp；FLAC ≈50–70% 原大小。
7. **预处理**：可逆变换不降熵，但去相关后可让"分量独立编码器"命中联合熵；有损管线靠量化真正降熵。
