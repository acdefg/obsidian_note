# 时钟切换
[5.4 Verilog 时钟切换 | 菜鸟教程](https://www.runoob.com/w3cnote/verilog2-clock-switch.html)

在两个电平相反的时候切换时钟，肯定有毛刺；电平相同的时候，即使不产生毛刺，时钟切换后的第一个时钟的周期或占空比也不是理想的。所以，为避免毛刺的产生，需要在两个时钟都为低电平的时候进行时钟切换。
module clk_switch(
	input rstn ,
	input clk1,
	input clk2,
	input sel_clk1 , // 1 clk1, 0 clk2
	output clk_out
	);

   reg [2:0] sel_clk1_r ;
   reg [1:0] sel_clk1_neg_r ;
   reg [2:0] sel_clk2_r ;
   reg [1:0] sel_clk2_neg_r ;

   //使用 3 拍缓存，同步另一个时钟控制信号与本时钟控制信号的 " 与 " 逻辑操作
   always @(posedge clk1 or negedge rstn) begin
	  if (!rstn) begin
		 sel_clk1_r <= 3'b111 ; //注意默认值
	  end
	  else begin
		 //sel clk1, and not sel clk2
		 sel_clk1_r <= {sel_clk1_r[1:0], sel_clk1 & (!sel_clk2_neg_r[1])} ;
	  end
   end

   //在下降沿，使用 2 拍缓存时钟选择信号
   always @(negedge clk1 or negedge rstn) begin
	  if (!rstn) begin
		 sel_clk1_neg_r <= 2'b11 ; //注意默认值
	  end
	  else begin
		 sel_clk1_neg_r <= {sel_clk1_neg_r[0], sel_clk1_r[2]} ;
	  end
   end

   //使用 3 拍缓存，同步另一个时钟控制信号与本时钟控制信号的 " 与 " 逻辑操作
   always @(posedge clk2 or negedge rstn) begin
	  if (!rstn) begin
		 sel_clk2_r <= 3'b0 ; //注意默认值
	  end
	  else begin
		 //sel clk2, and not sel clk1
		 sel_clk2_r <= {sel_clk2_r[1:0], !sel_clk1 & (!sel_clk1_neg_r[1])} ;
	  end
   end

   //在下降沿，使用 2 拍缓存时钟选择信号
   always @(negedge clk2 or negedge rstn) begin
	  if (!rstn) begin
		 sel_clk2_neg_r <= 2'b0 ; //注意默认值
	  end
	  else begin
		 sel_clk2_neg_r <= {sel_clk2_neg_r[0], sel_clk2_r[2]} ;
	  end
   end

   //时钟逻辑运算时，一般使用特定的工艺单元库。
   //这里用 Verilog 自带的逻辑门单元代替
   wire clk1_gate, clk2_gate ;
   and (clk1_gate, clk1, sel_clk1_neg_r[1]) ;
   and (clk2_gate, clk2, sel_clk2_neg_r[1]) ;
   or (clk_out, clk1_gate, clk2_gate) ;

endmodule

### 轮询仲裁（Verilog）：参考代码的两个 bug 与修正

**原理一句话**：用"上次被授权的位"把请求向量切成两段，先服务上次之后的那一段，空了再回绕到前面。

**完整推导见「二、C++ 题 → 轮询仲裁 / RR」**：C++ 实现、8 次授权的公平性表、三个边界条件都在那一节，两题共用同一套逻辑。

**上面那段参考代码的两个 bug（可当场验算）**

1. **没有回绕 → 低优先级饿死**。`grant` 是 4 位，而 `{1'b1,request} & ~({1'b1,request} - pre_state)` 是 5 位表达式。当"上次之后没有请求"时结果落在哨兵位 `bit4`，截断成 4 位后变成 0。
   反例：`request=4'b0011`、`pre_state=4'b0100` → `10011 - 00100 = 01111`，取反后与 `10011` 相与 = `10000` → `grant = 0`。位 0/1 明明在请求，却拿不到授权。
2. **`request == 0` 会把指针清零并永久锁死**。此时 `pre_grant` 低 4 位为 0，`pre_state` 被置 0；下一拍 `mask = ~({1'b1,req} - 0) = ~{1'b1,req}` → `grant` 恒为 0，仲裁器死掉。

**修正后的写法**（显式分开"选路"和"更新"）：

```verilog
module rr_arb #(parameter W = 4) (
    input  wire         clk,
    input  wire         rst_n,
    input  wire [W-1:0] request,
    output wire [W-1:0] grant
);
    reg  [W-1:0] last;                                  // 上次授权，one-hot
    wire [W-1:0] mask = (last == {W{1'b0}}) ? {W{1'b1}}
                                            : ~((last << 1) - 1'b1);
    wire [W-1:0] sel0 = request & mask;
    wire [W-1:0] sel  = (sel0 != 0) ? sel0 : request;   // 回绕
    wire [W-1:0] g    = sel & (~sel + 1'b1);            // 最低置位

    always @(posedge clk or negedge rst_n) begin
        if (!rst_n)      last <= {W{1'b0}};
        else if (g != 0) last <= g;                     // 无请求时保持
    end

    assign grant = g;
endmodule
```

# 序列检测（状态机）

**题目**：串行输入 `din`，检测出 `1011` 时输出一个周期的高电平。**默认按重叠检测**（`1011011` 要出两次）。
**考点**：状态定义、重叠时的回退边、Mealy / Moore 的取舍。

## 状态转移表（重叠检测）

| 当前状态 | 含义 | `din=0` | `din=1` |
|---|---|---|---|
| S0 | 无匹配 | S0 | S1 |
| S1 | 已匹配 `1` | S2 | **S1**（`11` 的最后一个 1 仍是开头） |
| S2 | 已匹配 `10` | **S0**（`100` 没有可用后缀） | S3 |
| S3 | 已匹配 `101` | **S2**（`1010` 的后缀 `10`） | **S1 + 输出 1**（`1011` 的后缀 `1`） |

**两条回退边是这题的全部难点**：`S1 --1--> S1` 和 `S3 --0--> S2`。写成 `S1 --1--> S0` 或 `S3 --0--> S0` 就是最常见的错——检测漏掉重叠。

## Mealy（输出比输入早一拍，组合输出）

```verilog
module seq_det_1011 (
    input  wire clk,
    input  wire rst_n,
    input  wire din,
    output reg  dout          // Mealy：与 din 同拍
);
    localparam S0 = 2'd0, S1 = 2'd1, S2 = 2'd2, S3 = 2'd3;
    reg [1:0] state, next;

    always @(posedge clk or negedge rst_n)
        if (!rst_n) state <= S0;
        else        state <= next;

    always @(*) begin
        next = state;
        case (state)
            S0: next = din ? S1 : S0;
            S1: next = din ? S1 : S2;
            S2: next = din ? S3 : S0;
            S3: next = din ? S1 : S2;
            default: next = S0;
        endcase
    end

    always @(*) dout = (state == S3) && din;   // 最后一位到的那一拍就输出
endmodule
```

## Moore（输出多一个状态，晚一拍但无毛刺）

加一个 `S4` 作为"已检测到"的状态，输出只由状态决定：

```verilog
localparam S0=3'd0, S1=3'd1, S2=3'd2, S3=3'd3, S4=3'd4;
// 转移：S3 --1--> S4；S4 --0--> S2，S4 --1--> S1
// 输出：dout = (state == S4)   → 寄存器输出，无组合毛刺
```

**取舍**：Mealy 少一个状态、早一拍，但输出依赖输入 → 有组合毛刺、时序路径长；Moore 多一个状态、晚一拍，输出干净。**面试时把这条取舍说出来，比写对更重要。**

## 移位寄存器写法（工程上更常用）

短序列（≤ 一个字宽）根本不需要状态机：

```verilog
reg [3:0] sr;
always @(posedge clk or negedge rst_n)
    if (!rst_n) sr <= 4'b0;
    else        sr <= {sr[2:0], din};

assign hit = (sr == 4'b1011);   // 天然支持重叠
```

代价与差别：**晚一拍**（`sr` 在时钟沿之后才包含当前的 `din`），但代码量是 FSM 的 1/5，且参数化只改比较字。**面试里主动提这个替代方案是加分项**——说明你知道"状态机不是唯一解"。

## 边界与追问

- **不重叠检测**：命中后直接回 `S0`（或清零 `sr`）。`1011011` 只出一次。
- **复位**：异步复位到 `S0`；`sr` 清零，否则上电残值可能误触发。
- **跨字节/跨事务**：状态机天然保持；移位寄存器方案要注意位序（`{sr[2:0], din}` 是先到的在高位还是低位）。
- **追问**：检测多个序列（并行 FSM + 优先级）、可配置序列（把比较字做成寄存器）、带通配符（用掩码比较 `(sr & mask) == pat`）。

# 二、C++ 题

# 轮询仲裁 / RR（C++ 实现）

**原理一句话**：用"上次被授权的位"把请求向量切成两段，**先服务上次之后的那一段，空了再回绕到前面**。指针每授权一次就前进一位，所以任何请求最多等 `W-1` 次别人的授权。

**C++ 版本（可直接跑，和面试口述一致）**

```cpp
class RoundRobinArbiter {
public:
    // 返回 one-hot 授权；无请求返回 0。last 只在真正授权时更新。
    unsigned grant(unsigned req) {
        const unsigned FULL = 0xFu;                       // W = 4
        unsigned mask = (last == 0) ? FULL
                                    : (~((last << 1) - 1) & FULL);
        unsigned sel  = req & mask;
        if (sel == 0) sel = req;                          // 回绕
        if (sel == 0) return 0;                           // 无请求：不改状态
        unsigned g = sel & (~sel + 1);                    // 最低置位
        last = g;
        return g;
    }
private:
    unsigned last = 0;                                    // 上次授权，one-hot
};
```

**`req = 0b1111` 连调 8 次**（验证公平性）：

| 次数 | last | mask | sel | grant |
|---|---|---|---|---|
| 1 | 0000 | 1111 | 1111 | **0001** |
| 2 | 0001 | 1110 | 1110 | **0010** |
| 3 | 0010 | 1100 | 1100 | **0100** |
| 4 | 0100 | 1000 | 1000 | **1000** |
| 5 | 1000 | 0000 | 0 → 回绕 1111 | **0001** |
| 6–8 | — | — | — | 0010 / 0100 / 1000 |

每个请求者恰好 2 次，顺序固定。**无饥饿证明**：授权 i 之后 `last=i`，优先级变成 `i+1, i+2, …, W-1, 0, …, i`，所以任何 pending 请求最多被 `W-1` 次他人的授权插队。

**三个边界（面试必问）**

- **`req == 0`**：返回 0，且 **`last` 必须保持不变**。若把它当成"授权给 0"，指针会被重置到一个固定位置，低优先级请求者永远等不到。
- **`last` 指向唯一请求**：`mask` 会把该位屏蔽掉（例如 `last=1000` 时 `mask=0000`），必须靠"`sel==0` 就回绕取 `req`"兜底。
- **`last` 不能同拍组合反馈**（`grant → last → grant`）：C++ 里同拍递归会死循环；对应 RTL 里就是组合环，不可综合。**`last` 必须打一拍。**

**追问延伸**：加权轮询（WRR，用 deficit 累加器而非单指针）、两级仲裁（先按 VC、再按请求者）、QoS 下的优先级 + 轮询混合。

# 最长无重复子串（滑动窗口）

**题目**：给字符串 `s`，返回不含重复字符的最长子串长度。
**考点**：`right` 扩张、`left` 收缩，用 `last[c]` 记录字符上次出现的下标。

```cpp
int lengthOfLongestSubstring(const string& s) {
    vector<int> last(128, -1);          // 字符集 128；扩展 ASCII 用 256
    int left = 0, ans = 0;
    for (int right = 0; right < (int)s.size(); ++right) {
        unsigned char c = s[right];
        if (last[c] >= left) left = last[c] + 1;   // 关键：只在这个字符还在窗口内时才跳
        last[c] = right;
        ans = max(ans, right - left + 1);
    }
    return ans;
}
```

**为什么不能写 `left = last[c] + 1`**：`last[c]` 可能落在窗口左边（已经滑过去了）。用 `abba` 验算：

| right | 字符 | last[c] | left 前 | 正确 left | 若直接赋值 |
|---|---|---|---|---|---|
| 0 | a | −1 | 0 | 0 | 0 |
| 1 | b | −1 | 0 | 0 | 0 |
| 2 | b | 1 | 0 | **2** | 2 |
| 3 | a | 0 | 2 | **2**（0 < 2，不动） | **1 ← 倒退，错** |

答案 2。等价写法：`left = max(left, last[c] + 1)`。

**边界**：空串返回 0；全相同字符返回 1；全不同返回 `n`；字符集不是 ASCII 时改用 `unordered_map<char,int>` 或按字节处理。

**追问**：返回子串本身（记录 `ans` 的起点）；最多 k 个不同字符（LC 340，窗口内种类数用计数数组维护）；最多替换 k 个字符（LC 424，窗口长度 − 出现最多字符的次数 ≤ k）。

# LRU Cache

**题目**：设计 `LRUCache(capacity)`，支持 `get(key)`（不存在返回 −1）和 `put(key, value)`，两者都要 O(1)；容量满时淘汰**最久未使用**的键。
**结构**：哈希表存 `key → 链表节点`，双向链表维护新旧顺序，**表头最新、表尾最旧**。

## 版本 A：用 STL（代码短，面试可先用它说清思路）

```cpp
class LRUCache {
public:
    explicit LRUCache(int capacity) : cap(capacity) {}

    int get(int key) {
        auto it = pos.find(key);
        if (it == pos.end()) return -1;
        data.splice(data.begin(), data, it->second);   // 移到表头
        return it->second->second;
    }

    void put(int key, int value) {
        auto it = pos.find(key);
        if (it != pos.end()) {                          // 已存在：更新 + 提新
            it->second->second = value;
            data.splice(data.begin(), data, it->second);
            return;
        }
        if ((int)data.size() == cap) {                  // 满：淘汰表尾
            pos.erase(data.back().first);
            data.pop_back();
        }
        data.emplace_front(key, value);
        pos[key] = data.begin();
    }

private:
    int cap;
    list<pair<int,int>> data;                           // 头部最新
    unordered_map<int, list<pair<int,int>>::iterator> pos;
};
```

## 版本 B：手写双向链表（面试官说"不许用 STL"时）

```cpp
struct Node {
    int key, val;
    Node *prev, *next;
    Node(int k, int v) : key(k), val(v), prev(nullptr), next(nullptr) {}
};

class LRUCache2 {
public:
    explicit LRUCache2(int capacity) : cap(capacity) {
        head = new Node(-1, -1);          // 哨兵：省掉空表/单节点的分支
        tail = new Node(-1, -1);
        head->next = tail;
        tail->prev = head;
    }

    int get(int key) {
        auto it = mp.find(key);
        if (it == mp.end()) return -1;
        detach(it->second);
        pushFront(it->second);
        return it->second->val;
    }

    void put(int key, int value) {
        if (cap <= 0) return;
        auto it = mp.find(key);
        if (it != mp.end()) {
            it->second->val = value;
            detach(it->second);
            pushFront(it->second);
            return;
        }
        if ((int)mp.size() == cap) {
            Node* victim = tail->prev;    // 最旧
            mp.erase(victim->key);
            detach(victim);
            delete victim;
        }
        Node* n = new Node(key, value);
        mp[key] = n;
        pushFront(n);
    }

private:
    int cap;
    unordered_map<int, Node*> mp;
    Node *head, *tail;

    void detach(Node* p) {
        p->prev->next = p->next;
        p->next->prev = p->prev;
    }
    void pushFront(Node* p) {
        p->next = head->next;
        p->prev = head;
        head->next->prev = p;
        head->next = p;
    }
};
```

**四个必踩的坑**

1. **`get` 命中后忘了提新** → 退化成 FIFO。
2. **`put` 已存在的 key 时只改值、忘了提新** → 同上。
3. **淘汰时先删链表再查 key** → 节点已经没了，`mp.erase` 找不到；顺序必须是"先读 `victim->key` → 从 map 删 → 从链表摘"。
4. **`cap == 0`** → `tail->prev` 就是哨兵 `head`，会删坏链表，必须提前返回。

**复杂度**：`get` / `put` 均 O(1)；空间 O(capacity)。

**追问**：线程安全（分段锁 / 读写锁 + 提新时的锁粒度）；LFU（多一个频次桶链表）；带 TTL（额外按过期时间排序的结构）；**组相联 cache 模拟（每个 set 一条 LRU 链）**——这一步直接接到 `cache-microarchitecture` 的 PLRU 条目。

# 反转单链表

```cpp
ListNode* reverseList(ListNode* head) {
    ListNode* prev = nullptr;
    while (head) {
        ListNode* nxt = head->next;   // 先存后继，否则断链后找不到
        head->next = prev;            // 反向
        prev = head;                  // 前进
        head = nxt;
    }
    return prev;                      // 返回 prev，不是 head（head 已是 nullptr）
}
```

递归版：

```cpp
ListNode* reverseList(ListNode* head) {
    if (!head || !head->next) return head;
    ListNode* newHead = reverseList(head->next);
    head->next->next = head;
    head->next = nullptr;             // 必须断掉，否则成环
    return newHead;
}
```

**边界**：空表返回 `nullptr`、单节点返回自身；三行顺序不能换（先存 `nxt`，再改 `head->next`，最后移动）。
**追问**：反转区间 `[m, n]`（LC 92，dummy 头 + 头插）、每 k 个一组反转（LC 25）、判断回文链表（找中点 + 反转后半 + 比较）。

# 动态规划

**四步法（写不出转移方程时按这个顺序想）**

1. **定义状态**：`dp[i]` / `dp[i][j]` 用一句人话说清楚（说不清就换定义）。
2. **转移方程**：当前状态由哪些更小的状态推来。
3. **初始化与边界**：`dp[0]`、越界下标、全负/全零。
4. **遍历顺序**：保证依赖项先算；滚动数组时注意**正序还是逆序**。

**高频题型**

| 题 | 状态定义 | 转移 | 复杂度 |
|---|---|---|---|
| 爬楼梯（70） | `dp[i]` = 到第 i 阶的方法数 | `dp[i]=dp[i-1]+dp[i-2]` | O(n) / O(1) |
| 最大子数组和（53） | `dp[i]` = **以 i 结尾**的最大和 | `max(a[i], dp[i-1]+a[i])` | O(n) / O(1) |
| 打家劫舍（198） | `dp[i]` = 前 i 间最多 | `max(dp[i-1], dp[i-2]+a[i])` | O(n) |
| 最长递增子序列（300） | `dp[i]` = **以 i 结尾**的 LIS 长度 | `1 + max(dp[j])`, `j<i, a[j]<a[i]` | O(n²)（贪心+二分 O(n log n)） |
| 零钱兑换（322） | `dp[x]` = 凑出 x 的最少硬币 | `min(dp[x-c]+1)` | O(amount·n) |
| 01 背包 | `dp[j]` = 容量 j 的最大价值 | `max(dp[j], dp[j-w]+v)`，**j 逆序** | O(nW) |
| 编辑距离（72） | `dp[i][j]` = `s[:i]→t[:j]` 的最少操作 | 增/删/替换取 min | O(mn) |
| 最长公共子序列（1143） | `dp[i][j]` | 相等 +1，否则取 max | O(mn) |
| 不同路径（62） | `dp[i][j]` = 路径数 | 上 + 左 | O(mn) |
| 买卖股票（121） | 维护最低价 + 最大利润 | 一遍扫描 | O(n) |

**代表题代码**

```cpp
// 53 最大子数组和
int maxSubArray(vector<int>& a) {
    int cur = a[0], best = a[0];
    for (int i = 1; i < (int)a.size(); ++i) {
        cur  = max(a[i], cur + a[i]);
        best = max(best, cur);
    }
    return best;
}
```

```cpp
// 322 零钱兑换
int coinChange(vector<int>& coins, int amount) {
    const int INF = amount + 1;              // 用 amount+1 代替 INT_MAX，避免 +1 溢出
    vector<int> dp(amount + 1, INF);
    dp[0] = 0;
    for (int x = 1; x <= amount; ++x)
        for (int c : coins)
            if (c <= x) dp[x] = min(dp[x], dp[x - c] + 1);
    return dp[amount] == INF ? -1 : dp[amount];
}
```

```cpp
// 01 背包（一维滚动）
int knapsack(int W, vector<int>& w, vector<int>& v) {
    vector<int> dp(W + 1, 0);
    for (int i = 0; i < (int)w.size(); ++i)
        for (int j = W; j >= w[i]; --j)      // 逆序：保证每件物品只用一次
            dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
    return dp[W];
}
```

**五个高频坑**

1. **状态定义含糊** → 转移写不出来。先写一句话再动手。
2. **`dp[0]` 漏初始化**，或求方案数时用了 `INF`。
3. **01 背包写成正序** → 同一件物品被重复使用，变成完全背包。
4. **求最小值时用 `INT_MAX` 直接 `+1`** → 溢出成负数；用 `amount+1` 这类哨兵值。
5. **区间 DP 的遍历顺序**：必须先枚举区间长度，再枚举起点。

**面试定位**：数字 IC / GPU 岗的 DP 一般只到 medium（爬楼梯、最大子数组、LIS、背包、编辑距离），不会考偏题。回答时先说"状态定义 → 转移 → 复杂度"，比直接背代码更得分。

# Z 字遍历数组

**先问清楚题面**。"Z 字遍历"至少有三种含义，面试官不会主动区分：

| 含义 | 典型题 | 输出 |
|---|---|---|
| 二维数组按**对角线**走，方向交替 | LeetCode 498 | 一条条斜线扫过去，偶数线向上、奇数线向下 |
| 字符串按 **Z 字形**排列后逐行读 | LeetCode 6 | 先排成 Z 形，再按行拼接 |
| **Z-order / Morton 序**（空间填充曲线） | 无固定题号 | 按位交错，让二维相邻元素在一维上相邻 |

**第一句就该问**："是二维数组按对角线遍历，还是字符串按行重排？"——问错方向比写错边界更亏。

## 版本一：矩阵对角线遍历（LC 498，最可能的含义）

按 `i+j = s` 分组，每条对角线上元素的下标和相同；偶数条从下往上，奇数条从上往下。

```cpp
vector<int> findDiagonalOrder(vector<vector<int>>& mat) {
    int m = mat.size(), n = mat[0].size();
    vector<int> res;
    for (int s = 0; s <= m + n - 2; ++s) {
        if (s % 2 == 0) {                  // 偶数线：从下往上
            int i = min(s, m - 1);
            int j = s - i;
            while (i >= 0 && j < n) { res.push_back(mat[i][j]); --i; ++j; }
        } else {                           // 奇数线：从上往下
            int j = min(s, n - 1);
            int i = s - j;
            while (j >= 0 && i < m) { res.push_back(mat[i][j]); ++i; --j; }
        }
    }
    return res;
}
```

**三个必须处理的边界**（`min` 就是为了它们）：
- 起点越界：偶数线起点 `i` 可能超过 `m-1`，奇数线起点 `j` 可能超过 `n-1`；
- 终止条件两条都要写，只写一条会越界；
- 空矩阵先判 `m == 0 || n == 0`。

验算 `[[1,2,3],[4,5,6],[7,8,9]]` → `1,2,4,7,5,3,6,8,9`。

**另一种写法**：维护 `dir` 方向标志，走到边界时转向。代码更短但边界分支多（四个角各不同），面试时更容易写错。**推荐上面的"按 i+j 分组"**，因为方向是显式的。

## 版本二：字符串 Z 字形变换（LC 6）

```cpp
string convert(string s, int numRows) {
    if (numRows == 1) return s;           // 不判会死循环
    vector<string> rows(numRows);
    int r = 0, step = 1;
    for (char c : s) {
        rows[r] += c;
        if (r == 0)              step = 1;
        else if (r == numRows-1) step = -1;
        r += step;
    }
    string res;
    for (auto& x : rows) res += x;
    return res;
}
```

**考点**：周期是 `2*numRows - 2`；`numRows == 1` 必须早返回；不要真的去构造二维矩阵（空间 O(n·rows)），按行收集是 O(n)。

## 版本三：Morton 序 / Z-order（硬件岗的加分项）

把二维坐标的二进制位**交错**成一维：

```cpp
uint32_t part1by1(uint32_t x) {           // 把低 16 位展开到偶数位
    x = (x | (x << 8)) & 0x00FF00FF;
    x = (x | (x << 4)) & 0x0F0F0F0F;
    x = (x | (x << 2)) & 0x33333333;
    x = (x | (x << 1)) & 0x55555555;
    return x;
}
uint32_t morton(uint32_t x, uint32_t y) {
    return part1by1(x) | (part1by1(y) << 1);   // x 放偶数位，y 放奇数位
}
```

**为什么硬件岗会喜欢这个答案**：纹理和 tile 存储器用 **swizzle / Morton 序**重排地址，让二维上相邻的数据在一维上也相邻——这样一次 burst 取回来的就是一个 tile，bank conflict 和行冲突都更少。这和 [[cache-microarchitecture]] 里的访存合并是同一类问题。

## 边界与追问

- 空矩阵 / 空串、单行、单列、`numRows == 1`、`numRows > len(s)`；
- 追问："不用额外空间能做吗？"（对角遍历可以按索引直接算，但代码可读性变差）；
- 追问："如果是三维 Z-order 呢？"（三个坐标各展开，占 3 个相位：`| (p<<1) | (p<<2)`）。
