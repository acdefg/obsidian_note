## 1. Verilog 同步 FIFO

### 要求

- 深度 `DEPTH`，位宽 `DW`，支持同时读写
- `full` / `empty` 不能同时为 1
- 复位后 `empty=1`
- 写满后 `wr_en` 无效；读空后 `rd_en` 无效

### 脚手架

```verilog
module sync_fifo #(
    parameter int DW    = 32,
    parameter int DEPTH = 8,          // 必须是 2 的幂
    localparam int AW   = $clog2(DEPTH)
)(
    input  logic          clk,
    input  logic          rst_n,
    input  logic          wr_en,
    input  logic          rd_en,
    input  logic [DW-1:0] wdata,
    output logic [DW-1:0] rdata,
    output logic          full,
    output logic          empty,
    output logic [AW:0]   count
);
    logic [DW-1:0] mem [0:DEPTH-1];
    logic [AW-1:0] wr_ptr, rd_ptr;

    // TODO(你): count 更新 + full/empty 生成 + 读写指针
    // 提示：用 count 而不是多留一个空位；同时读写时 count 的 +/- 条件要想清楚
    // assign full  = ...
    // assign empty = ...

endmodule
```

### 自测用例

1. 连续写 `DEPTH` 次 → `full=1`, `count=DEPTH`
2. 连续读 `DEPTH` 次 → `empty=1`, `count=0`
3. 同时读写 → `count` 不变，数据顺序正确
4. 空读 / 满写 → 状态不变
5. 复位 → `empty=1`, `count=0`
